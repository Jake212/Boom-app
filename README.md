# ClearHelp

A plain-English tech-help chatbot for older adults. Ask a question about your phone, computer, or the internet and get simple, step-by-step guidance — large text, high contrast, no jargon.

Open `index.html` in a browser to use it. It answers common questions (Wi-Fi, passwords, scams, video calls, printers, backups, and more) instantly with no setup required, using a built-in knowledge base.

Optionally, you can connect your own Google Gemini API key (Settings → "Connect your own AI key") for open-ended questions beyond the built-in topics — the key is stored only in your browser's local storage and is never committed to this repo.
