# ClearHelp

A tech-troubleshooting chat for older adults, inspired by the simplicity of chatting with an AI assistant — no menus to figure out, just tell it what's wrong in your own words. Large text, high contrast, no jargon.

Open `index.html` in a browser to use it. You land straight in a conversation: a warm greeting, a few suggested questions to tap if you're not sure how to describe the problem, and a message box right there — the same way you'd type to Claude. It answers 54 common questions (Wi-Fi, passwords, scams, video calls, printers, backups, health portals, bill pay, and more, across 12 categories) instantly with no setup required, using a built-in knowledge base. Each guide breaks the fix into small, numbered steps with concrete visual landmarks ("look for a paperclip icon", "usually in a top corner") rather than compressed multi-part instructions, so each step is one simple action. Tap "📚 Guides" any time to search or browse the full library instead.

You can also tap the microphone button to ask a question by voice instead of typing, and tap the 🔊 icon on any reply to have it read aloud — both use your browser's built-in speech features, with no data sent anywhere. If you'd rather not tap for every reply, turn on "Read replies out loud automatically" in Settings and every answer will be spoken as soon as it appears.

Optionally, you can connect your own Google Gemini API key (Settings → "Connect your own AI key") for open-ended questions beyond the built-in topics — the key is stored only in your browser's local storage and is never committed to this repo. Saving a key tests it immediately and reports clearly if it's invalid or out of quota, and the AI remembers the conversation so far (including anything already answered by the built-in guides), so natural follow-up questions work.

The same key also powers AI search inside 📚 Guides: if your exact words don't match any guide's keywords (e.g. "my headphones won't connect to anything"), a "🤖 Search with AI" button appears and semantically matches your question against all 54 guides, marking results with an AI badge.

For problems that need more than plain-language steps, ClearHelp links out to trusted, more technical communities: [iFixit](https://www.ifixit.com/) for hands-on repair guides, [Tom's Hardware Forum](https://forums.tomshardware.com/) and [Super User](https://superuser.com/) for PC/software troubleshooting, [Bleeping Computer](https://www.bleepingcomputer.com/) for malware removal, and [Reddit's r/techsupport](https://www.reddit.com/r/techsupport/) for general help. Relevant guides show a "Want more detail?" link to the best-fit source; the footer's "More technical help" button lists all five.
